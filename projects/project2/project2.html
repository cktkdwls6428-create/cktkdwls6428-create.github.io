Galaxy Watch7 Animated KV

shading & texturing , animation , compositing , solo project

Tools Used

Cinema 4D / Redshift / DaVinci Resolve (Fusion)

Description

전 회사인 포스트프로덕션에서는 2D와 3D 업무가 명확하게 구분되어 있었지만, 시그니처에서는 하나의 결과물을 완성하기 위해 2D와 3D 작업을 함께 수행해야 했습니다. 기존에는 3D 작업을 주로 담당했기 때문에 별 효과와 같은 2D 작업을 직접 진행하는 것이 처음에는 익숙하지 않았습니다.

이를 해결하기 위해 주변 작업자들에게 적극적으로 질문하고 작업 방식을 배우면서 필요한 부분을 하나씩 익혔습니다. 단순히 도움을 받는 것에 그치지 않고 배운 내용을 직접 작업에 적용하며 2D와 3D 요소를 함께 구성했고, 수정과 보완을 반복하며 최종 결과물까지 직접 완성했습니다.

기존에 경험하지 못했던 업무 영역이었지만, 필요한 부분을 스스로 배우고 주변의 경험을 활용해 부족한 부분을 채워가며 하나의 결과물을 끝까지 완성한 프로젝트입니다.
