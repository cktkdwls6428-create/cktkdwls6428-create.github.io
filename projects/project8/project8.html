Samsung Dotcom Mother's Day

shading & texturing , AI generated video , compositing

Tools Used

Maya / Solo project

Description

폰 안쪽에 들어가는 아이 그림 영상을 AI를 활용하여 제작했습니다. 기존 방식으로 직접 제작했다면 많은 시간과 작업이 필요했을 영상이지만, AI를 활용해 원하는 이미지를 빠르게 생성하고 다양한 방향을 테스트하며 제작 시간을 줄일 수 있었습니다.

하지만 AI가 한 번에 원하는 결과물을 만들어주는 것은 아니었습니다. 특히 그림의 디테일이나 움직임이 의도와 다르게 표현되는 경우가 많았고, 원하는 느낌을 정확하게 구현하기 위해 반복적인 수정이 필요했습니다. 이를 해결하기 위해 결과물을 계속 확인하며 프롬프트의 표현과 조건을 세밀하게 수정하고, 필요한 정보를 추가해 여러 번 생성하는 과정을 반복했습니다. 단순히 한 번 생성하고 사용하는 것이 아니라 원하는 결과가 나올 때까지 프롬프트를 계속 발전시키며 AI를 활용했습니다.

이를 통해 AI를 단순한 이미지 생성 도구가 아니라, 원하는 결과를 얻기 위해 사용자가 방향을 제시하고 결과물을 지속적으로 개선해야 하는 제작 도구로 경험할 수 있었습니다.
